CORS Setup Required — Read Before Fetching

▲ COLLAPSE

This app runs directly in your browser. AlienVault OTX blocks cross-origin requests from local files by default (CORS policy). You need a browser extension to inject the missing headers — takes 60 seconds.

1
Install a CORS-unblocking extension
Do not use FoxyProxy — that's a proxy router, not a CORS fix. Install one of these instead:
■ CORS Unblock (Chrome) ■ Allow CORS (Chrome) ■ CORS Everywhere (Firefox)
2
Enable the extension
Click the extension icon in your browser toolbar and toggle it ON. The extension intercepts responses from OTX and injects Access-Control-Allow-Origin: * so your browser accepts them.
3
Paste your OTX API key below and fetch
Get your key from otx.alienvault.com/api → "Your API Key". Paste it in the field below and click Fetch IOCs.
4
Turn the extension OFF after you're done
These extensions disable CORS protection globally. Only keep it on while using this tool — toggle it off before normal browsing.
⚠ Security note: CORS extensions weaken your browser's same-origin protection. Use them only on trusted pages and disable immediately after use.

abuse.ch IOC Exporter

Generate a PowerShell one-liner to fetch IOCs from MalwareBazaar, URLhaus, and ThreatFox. Paste your Auth-Key, pick providers, copy the command, run in PowerShell. No CORS, no extensions, no server.

How it works: This page generates a PowerShell command with your Auth-Key baked in. You copy it, paste it into PowerShell, and it fetches IOCs directly from abuse.ch APIs — exporting CSV + TXT files to an abuse_ch_iocs folder. This page makes no API calls of its own — it only builds text (it does load webfonts from Google). Your key goes to your clipboard and your shell, so treat the clipboard as tainted until you overwrite it.

Security Checklist — Before Fetching
  • ✓Close all other browser tabs — CORS extensions affect every tab. Other sites could exploit the open policy while the extension is active.
  • ✓Verify your CORS extension is ON — check the toolbar icon. If the green "CORS is working" banner is shown you do not need the extension at all; leave it off.
  • ✓Use a throwaway OTX key — it lives in this page's memory. Never paste a production or shared credential.
  • ✓Use a dedicated browser profile if possible — isolates cookies and sessions from your main browsing profile.
  • ✓Do not browse other sites while the extension is enabled — fetch your IOCs, export, then disable immediately.
This checklist shows once per session. Subsequent fetches and page loads won't show it again.
